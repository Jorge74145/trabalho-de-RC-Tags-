Guia Explicativo das Tags HTML do Ficheiro index.html

1. Estrutura Base e Metadados

Tag Descrição e Função
<!DOCTYPE html> Declaração inicial que indica ao navegador que o documento utiliza o padrão HTML5.
<html> Elemento raiz que envolve todo o conteúdo do documento HTML. O atributo lang="pt-pt" especifica o idioma português de Portugal.
<head> Contentor para os metadados da página (informações técnicas não exibidas diretamente no corpo visual).
<meta> Define metadados como a codificação de carateres (UTF-8) e a configuração da área de visualização (viewport) para responsividade em dispositivos móveis.
<title> Define o título da página que aparece no separador do navegador e nos resultados de pesquisa.
<link> Estabelece a ligação entre o documento HTML e recursos externos, neste caso, o ficheiro de estilos CSS (style.css).
<body> Contém todo o conteúdo visível da página Web (textos, imagens, botões, formulários, etc.).

2. Estrutura de Layout e Semântica de Conteúdo

Tag Descrição e Função
<header> Representa o cabeçalho inicial da página ou de uma secção, contendo títulos e o logótipo/apresentação.
<nav> Define um bloco de links de navegação principal do website.
<main> Identifica o conteúdo central e único da página, excluindo conteúdos repetidos como cabeçalhos e rodapés gerais.
<section> Agrupa um bloco de conteúdo temático autónomo dentro do documento.
<article> Representa uma composição independente e auto-contida (ex: cartão de produto individual).
<aside> Define conteúdo secundário ou de apoio relacionado com o tema principal (ex: opiniões de clientes, estado de rastreio).
<footer> Representa o rodapé do documento, contendo informações de direitos de autor e contactos.
<div> Contentor genérico em bloco usado para agrupar elementos com fins de estilização CSS ou manipulação via JS.
<hr> Cria uma separação temática ou linha horizontal divisória na página.

3. Texto, Títulos e Formatação

Tag Descrição e Função
<h1> até <h6> Títulos hierárquicos do documento, onde o <h1> é o título principal e o <h6> o subnível mais baixo.
<p> Representa um parágrafo de texto standard.
<a> Cria um hiperlink para navegar para outros ficheiros, âncoras internas (#id) ou links de e-mail (mailto:).
<blockquote> Destaca uma citação em bloco proveniente de outra fonte ou testemunho de cliente.
<strong> Aplica um destaque semântico de forte importância ao texto (apresentado visualmente a negrito).
<pre> Exibe texto pré-formatado mantendo todos os espaços e quebras de linha exatas no código.
<address> Fornece informações de contacto do autor, empresa ou proprietário do site.
<br> Insere uma quebra de linha simples no texto.

4. Listas e Listas de Descrição

Tag Descrição e Função
<ul> Cria uma lista não ordenada (normalmente apresentada com pontos/bullets).
<ol> Cria uma lista ordenada (apresentada de forma numerada sequencialmente).
<li> Define um item individual dentro de uma lista (<ul> ou <ol>).
<dl> Define uma lista de descrições/definições.
<dt> Representa o termo ou nome a ser especificado dentro de uma <dl>.
<dd> Representa o valor ou a descrição associada ao termo <dt>.

5. Multimédia e Elementos Gráficos

Tag Descrição e Função
<figure> Agrupa um conteúdo multimédia (imagem, vídeo) e a sua respetiva legenda.
<figcaption> Define a legenda explicativa do conteúdo presente na tag <figure>.
<img> Insere uma imagem na página web através do atributo src.
<video> Incorpora um leitor de vídeo com controlos de reprodução integrados.
<source> Especifica o ficheiro de media e o tipo (ex: video/mp4) para elementos como <video>.
<canvas> Define uma área gráfica onde é possível desenhar formas, gráficos e gradientes utilizando scripts em JavaScript.

6. Tabelas de Dados

Tag Descrição e Função
<table> Cria uma estrutura de tabela para exibição de dados bidimensionais.
<thead> Agrupa os cabeçalhos das colunas de uma tabela.
<tbody> Agrupa os dados principais (as linhas) da tabela.
<tfoot> Agrupa as linhas de resumo ou notas de rodapé de uma tabela.
<tr> Define uma linha dentro da tabela (Table Row).
<th> Define uma célula de cabeçalho com texto em destaque (Table Header).
<td> Define uma célula normal de dados numa tabela (Table Data).

7. Formulários e Interatividade

Tag Descrição e Função
<form> Cria um formulário interativo para recolher dados preenchidos pelo utilizador.
<fieldset> Agrupa visualmente e semanticação campos relacionados dentro de um formulário.
<legend> Especifica o título ou legenda explicativa do bloco <fieldset>.
<label> Define um rótulo de texto associado a um elemento de entrada (através do atributo for).
<input> Campo de entrada onde o utilizador insere dados (ex: tipos text e email).
<select> Cria um menu suspenso de seleção de opções (dropdown).
<option> Define cada opção individual selecionável dentro do menu <select>.
<textarea> Campo de texto multilinha para inserção de mensagens mais extensas ou observações.
<button> Cria um botão clicável para submeter formulários ou acionar interações via JavaScript.

8. Scripts e Resposta a Suporte

Tag Descrição e Função
<script> Liga ou insere código executável JavaScript (neste caso, carrega o ficheiro script.js).
<noscript> Apresenta um conteúdo alternativo caso o navegador não suporte ou tenha o JavaScript desativado.
